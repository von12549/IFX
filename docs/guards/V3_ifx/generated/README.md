# Generated IFX .NET projects

`stages/` is generated by `scripts/Invoke-V3.ps1` from `profiles/ifx/` and the V3 C# templates. `dotnet/LayerGuard/` is generated by `scripts/Invoke-IFX.ps1` from the local .NET template. Both are checked in for review and are byte-checked by their respective `-Mode Check` commands. Build-only `bin/` and `obj/` directories are ignored.

Edit the profile, policy, or template source, then rerun `Generate`; do not make durable edits only in these output directories. CI is not activated by generation alone.
