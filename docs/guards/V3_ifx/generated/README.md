# Generated IFX .NET projects

`stages/` is generated by `scripts/Invoke-V3.ps1` from `profiles/ifx/` and the V3 C# templates, checked in for review and byte-checked by `-Mode Check`. Build-only `bin/` and `obj/` directories are ignored.

The Architecture Conformance Gate has no generated copy since Plan 06 P6.1: `scripts/Invoke-IFX.ps1` builds, tests and scans `templates/ifx-layerguard/` directly, and fails if `dotnet/LayerGuard/` appears again.

Edit the profile, policy, or template source, then rerun `Generate`; do not make durable edits only in these output directories. CI is not activated by generation alone.
