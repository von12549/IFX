once. Windows product evidence requires 37 suites, 191 core cases, 180
capability variants, 42 lock controls, clean/violation/missing/zero-match,

attempted once. Under C6c22 Linux is a visible, non-blocking portability
assessment for the Windows-only IFX product and is not V4 release certification.

The report records each module's start/completion/duration/result/declared
timeout, Host workspace-evidence use, fallback and issues. Success or failure
ends phase 1 immediately. No automatic repair or second C6c run is permitted.
